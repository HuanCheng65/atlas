# Atlas

Operational memory for this project. Maintained jointly by you and your agent
via the `atlas-*` skills under `.claude/skills/`.

## Layout

```
docs/atlas/
├── ROADMAP.md              current milestones, short-term goals
├── _templates/             entity templates (edit to change schema)
│   ├── decision.md
│   ├── experiment.md
│   └── question.md
├── journal/                append-only event log (filled by atlas-session-end)
│   └── YYYY-MM-DD-slug.md
├── decisions/              D-NNN: long-term architectural choices
│   ├── _index.md           auto-generated by reindex.py
│   └── D-NNN-*.md
├── experiments/            E-NNN: research runs (research projects only)
│   ├── _index.md
│   └── E-NNN-*.md
├── questions/              Q-NNN: open questions
│   ├── _index.md
│   └── Q-NNN-*.md
└── topics/                 free-form long-form notes, emerge from journal
    └── *.md
```

## Conventions

- Journal is append-only. Past entries record what happened.
- Entities (D/E/Q) are mutable but their schema is enforced by validate.py.
- `_index.md` files are derived. Regenerated by reindex.py. Do not hand-edit.
- Templates define schema. To change the schema, edit _templates/ and re-run validate.py.
